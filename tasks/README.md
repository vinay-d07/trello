# Task packs

Each practice day's material lives in `tasks/day-XX/` on branch `pack/day-XX`:

- `TASK.md`: tickets written like an interview prompt (symptoms, timebox, acceptance criteria)
- `SOLUTION.md`: root causes and model answers. **Open only after your timer ends.**

Generate a pack by asking Claude Code (see Guide.md → Appendix), e.g.
`Generate Day 4 task pack: 5 backend bugs`.
